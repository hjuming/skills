# Skills WEDO Public Web Manifest

Last updated: 2026-07-16

This repository stays private. The public export contains the static website **plus a selected subset of skills**. See `REPO_MAP.md` for the full three-repo model.

## Public / Private Principle (SSOT)

- **Public** = collected, non-WEDO, low-churn skills (general-purpose, safe to share).
- **Private** = WEDO-specific workflow skills + payment skills. These keep changing with the SSOT and never leave this private repo.
- The gate for "what is public" is the selection list in `web/skills-data.js`. Only skills whose `id` appears there are exported. `scripts/verify-public-skills.sh` is a backstop that also blocks `wedo-*` and payment skills by name.

## Release Strategy

- Keep this full working repository private.
- Publish the export generated by `scripts/export-public.sh` (website + selected skills), which runs the verify gate before syncing.
- Never publish the full `skills/` tree, historical archives, internal workflow files, or root project documents — only the selected subset defined above.

## Explicitly Excluded

Do not publish these paths from the working repository:

- any skill under `skills/` **not** listed in `web/skills-data.js`
- all `wedo-*` skills and all payment skills (`ecpay`, `newebpay*`, `payuni`, `payment-help`, `pci-compliance`) — always private
- `web/content/`
- `web/pages/`
- `web/design/`
- `web/.htaccess`

- `web/README.md`
- root historical setup guides and internal status documents
- `.git/` history from the private working repository

## Public Export Command

```bash
scripts/export-public.sh
```

This one command: (1) builds the website + selected skills into a temp dir, (2) runs `verify-public-skills.sh`, and (3) rsyncs into `_public_web/` while preserving `_public_web/.git`. `_public_web/` is ignored by Git in this private working repository and is the working tree of the public repo `hjuming/skills`.

## Verification

`export-public.sh` runs the gate automatically. To check manually:

```bash
scripts/verify-public-skills.sh          # policy: only selected, no wedo-*/payment
scripts/scan-public-export-secrets.sh _public_web   # no secrets
find _public_web -type f | sort          # allowlisted files + selected skills only
```
